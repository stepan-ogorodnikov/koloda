## Internationalization (i18n)

- **Message ID naming**: dot-separated `kebab-case` segments (e.g., `settings.hotkeys.ui.focus-next`); never camelCase or PascalCase.
- **Extract messages (demo)**: `nx run demo:lingui-extract --clean`
- **Compile messages (demo)**: `nx run demo:lingui-compile`
- **Extract messages (desktop)**: `nx run native-electron-react:lingui-extract --clean`
- **Compile messages (desktop)**: `nx run native-electron-react:lingui-compile`
- **Translation workflow**: Extract → Add translations to .po files → Compile
